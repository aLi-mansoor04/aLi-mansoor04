### 🚀 Featured Projects

#### 1. [Agentic Natural Language-to-SQL System](https://github.com/aLi-mansoor04/Natural-language-to-SQL-query)
> Converts natural language queries into safe, validated SQL using LangGraph state-graphs and dynamic schema grounding.
- **Stack:** `Python` • `LangGraph` • `LangChain` • `Groq` • `FAISS` • `Streamlit`
- **Cyclic LangGraph Architecture:** Built stateful execution flows with FAISS schema retrieval, context retention across multi-turn queries, and self-correction error recovery.
- **Safety & Guardrails:** Designed a human-in-the-loop confirmation flow for write/update operations to prevent destructive executions.
- **Full-Featured Interface:** Streamlit UI featuring query history, generated SQL inspection, real-time data visualizer, and JSON data exports.

#### 2. [AI Multi-Agent Research System](https://github.com/aLi-mansoor04/ai-research-agent)
> Autonomous 5-agent research pipeline performing real-time web retrieval, report synthesis, and self-reflection loops.
- **Stack:** `Python` • `LangGraph` • `LangChain` • `Tavily` • `Streamlit`
- **5-Agent Workflow:** Orchestrated `Search` → `Scrape` → `Write` → `Critique` → `Refine` nodes inside a cyclic state machine.
- **Autonomous Self-Reflection:** Integrated an automated critic agent that evaluates factual grounding and tone, triggering iterative revisions without human intervention.
- **Real-Time Tracking:** Live agent execution telemetry with Tavily + BeautifulSoup extraction and downloadable Markdown/TXT reports.

#### 3. [AI-Powered Conversational RAG Chatbot](https://github.com/aLi-mansoor04/conversational-rag-chatbot)
> Context-aware document Q&A assistant with conversational memory and low-latency Groq inference.
- **Stack:** `Python` • `LangGraph` • `LangChain` • `FAISS` • `Streamlit`
- **End-to-End Ingestion:** Modular document parsing, semantic chunking, embedding generation, and vector indexing using FAISS.
- **Contextual Retrieval:** Combined short-term conversational memory with vector similarity search for coherent multi-turn responses.
- **Rapid Inference:** Deployed on Streamlit with Groq-hosted open-weights LLMs for fast token streaming.
